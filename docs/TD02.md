## 2. Helper Functions

Two helper functions were implemented to retrieve the first and last closing prices of a financial asset.

### `get_first_close(prices)`

```python
def get_first_close(prices):
    return float(prices[0]["close"])
```

- **Purpose:** Retrieves the first closing price from a list of market observations.
- **Input:** `prices` — a list of dictionaries containing price data.
- **Output:** The first closing price as a float.
- **How it works:** Selects the first observation using `prices[0]`, extracts its `"close"` value, and converts it into a float.

### `get_last_close(prices)`

```python
def get_last_close(prices):
    return float(prices[-1]["close"])
```

- **Purpose:** Retrieves the last closing price from a list of market observations.
- **Input:** `prices` — a list of dictionaries containing price data.
- **Output:** The last closing price as a float.
- **How it works:** Selects the last observation using `prices[-1]`, extracts its `"close"` value, and converts it into a float.

### Expected Results

| Asset | First Close | Last Close |
|-------|-------------|------------|
| AAPL | 250.00 USD | 266.20 USD |
| SP500 | 6600.00 | 6742.00 |

**Note:** Both functions assume that observations are chronologically ordered and that the input list is not empty. The `float()` conversion ensures that closing prices are treated as numeric values rather than strings.

## 3. Main.py Functions

The `src/main.py` file contains several functions responsible for loading, filtering, and displaying financial market data.

### `load_instruments()`

- **Purpose:** Loads financial instrument information from `data/sample/instruments.json`.
- **How it works:** Uses `json.load()` to read the JSON file.
- **Output:** A dictionary containing information about the instrument and its benchmark.

### `load_prices()`

- **Purpose:** Loads historical market prices from `data/sample/prices.csv`.
- **How it works:** Uses `csv.DictReader()` to read the CSV file and converts the observations into a list.
- **Output:** A list of dictionaries containing market observations.

### `filter_prices(prices, ticker)`

- **Purpose:** Filters market observations for a specific financial asset.
- **Input:** A list of observations and a ticker (AAPL or SP500).
- **How it works:** Uses a list comprehension to select only the rows matching the specified ticker.
- **Output:** A filtered list containing 21 observations for the selected asset.

### `display_market_summary(asset, prices, show_currency=True)`

- **Purpose:** Displays a structured and reusable summary of a financial asset.
- **Input:** Asset information, filtered price observations, and an optional currency display parameter.
- **How it works:** Calls `get_first_close()` and `get_last_close()` to retrieve closing prices, then displays the relevant information.

**Displayed information:**
- Asset ticker and name.
- Number of observations.
- First closing price.
- Last closing price.
- Currency, when requested.

The optional `show_currency` parameter determines whether the asset's currency is displayed.

This function can be reused for both the instrument and its benchmark, avoiding duplicated code.

### `main()`

- **Purpose:** Coordinates the execution of the MarketPulse application.

**Execution steps:**

1. Loads instrument information from the JSON file.
2. Loads historical market prices from the CSV file.
3. Identifies the instrument (AAPL) and benchmark (SP500).
4. Filters price observations for each ticker.
5. Displays the market configuration.
6. Calls `display_market_summary()` for both financial assets.

The application is executed through:

```python
if __name__ == "__main__":
    main()
```
